# USF Product Roadmap (Provisional)

## Vision
A product-neutral software factory with portable AI workflows and, initially, a native macOS workspace. The factory can later evolve into a collaborative platform without forcing every generated project into the same architecture.

## Stage 1 — Foundations
- Product discovery, PRD, epics, stories, acceptance criteria
- Product form-factor assessment and architecture decision workflows
- PDR/ADR artifacts and traceability
- Portable skills and tool-specific adapters
- Quality and security conventions

## Stage 2 — Local desktop workspace
Provisional candidate: SwiftUI interface, modular local core, SQLite metadata store, project artifacts in user-controlled workspaces, adapter layer for coding agents, local execution manager. Validate this through a product/architecture decision before implementation.

## Stage 3 — Orchestration
- Agent/task execution with permission boundaries
- Test and review gates
- Execution history and audit trail
- Recovery, retries, cancellation, and failure handling

## Stage 4 — Optional platform services
Consider a backend only when validated needs require shared identity, collaboration, remote execution, centralized governance, sync, or reporting. Start with the simplest architecture that meets those requirements; microservices require a separate justification.

## Explicit non-goals for the initial stage
- Do not require cloud services for a useful local workflow.
- Do not build microservices before demonstrating the need.
- Do not assume every project generated by USF should be a macOS app.
- Do not treat all AI coding tools as interchangeable.
